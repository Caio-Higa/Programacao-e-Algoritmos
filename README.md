# Programacao-e-Algoritmos
Repositório para as aulas de Programação e Algoritmos

Ideia de CRUD: Organizador de ficha do RPG Ordem Paranormal inspirado no site Cris
- Create: Cria o nome, classe, origem e atributos
- Read: Lê as informações da ficha, classe e atributos, para alterar outros pontos da ficha, como a vida.
- Update: Pode modificar a classe, origem, atributos ou nome
- Deletar: Pode apagar o personagem completo

# Programacao-e-Algoritmos
Repositório para as aulas de Programação e Algoritmos

Ideia de CRUD PESSOAL: Organizador de ficha de D&D estilo Cris
- Create: Cria o nome, classe, origem, raça
- Read: Lê o tipo de classe e raça para entregar subclasses/raças específicas
- Update: Pode modificar as classes ou raças
- Deletar: Pode apagar uma classe ou o personagem completo

Ideia de CRUD: Sistema de entrega do IFOOD:
- Create: Escolhe os pedidos
- Read: Lê o pedido e fala o preço, somando tudo
- Update: Pode modificar o pedido
- Deletar: Pode apagar um item ou o pedido inteiro.
